KMP NUSANTARA v1.2 - USER MANUAL

Terima kasih telah menggunakan KMP Nusantara. Berikut adalah panduan singkat untuk mengoperasikan engine audio ini agar mendapatkan performa maksimal.

1. Persiapan File Audio

  • Pastikan file audio berformat .wav (PCM 16-bit direkomendasikan).
  • Beri nama file sesuai tombol yang diinginkan (Contoh: A.wav, S.wav, Q.wav).
  • Letakkan file-file tersebut di dalam folder sample yang Anda pilih saat aplikasi dijalankan.

2. Kontrol Utama

  • Main Pad: Tekan tombol Q-W-E-R-T-Y (dan baris lainnya) untuk memainkan suara.
  • NFS (New Folder System): Gunakan menu navigasi untuk berpindah antar folder sample secara cepat tanpa menutup aplikasi.
TIPS PERFORMA: Gunakan driver audio standar yang stabil. Jika suara terasa pecah, pastikan sample rate file WAV Anda berada di kisaran 44.1kHz atau 48kHz.

3. Troubleshooting

  • Tidak ada suara? Pastikan file audio tidak korup dan volume sistem aktif.
  • Aplikasi Crash? Pastikan Anda tidak menghapus folder sample saat aplikasi sedang membaca data.
