BAB 01 / 06
Variabel &
Tipe Data
// Cara JavaScript menyimpan informasi
Variabel adalah wadah untuk menyimpan data.

Ada 3 kata kunci:
• let → nilai bisa diubah
• const → nilai tidak bisa diubah
• var → cara lama, hindari

Tipe data dasar:
• "teks" → String
• 42, 3.14 → Number
• true / false → Boolean
• null, undefined → kosong / belum ada nilai
💡 Gunakan const secara default. Pakai let hanya kalau nilainya perlu diubah.

BAB 02 / 06
Operator
// Melakukan operasi pada data
Operator Aritmatika:
+ tambah   - kurang   * kali   / bagi   % sisa bagi

Operator Perbandingan:
=== sama persis   !== tidak sama
> lebih dari   < kurang dari

Operator Logika:
&& dan (AND)   || atau (OR)   ! bukan (NOT)

⚠️ Hati-hati: == vs ===
5 == "5" → true (bandingkan nilai saja)
5 === "5" → false (bandingkan nilai + tipe)

BAB 03 / 06
Kondisi
if / else
// Buat keputusan berdasarkan kondisi
if menjalankan kode jika kondisi true.
else dijalankan jika kondisi false.
else if untuk kondisi tambahan.

Struktur:
if (kondisi) {
  // jalankan ini
} else if (kondisi lain) {
  // atau ini
} else {
  // atau ini
}

Ternary — cara singkat:
kondisi ? "ya" : "tidak"

BAB 04 / 06
Perulangan
(Loop)
// Jalankan kode berulang kali
for — tahu berapa kali mengulang:
for (mulai; kondisi; langkah) { ... }

while — ulang selama kondisi true:
while (kondisi) { ... }

for...of — loop tiap elemen array:
for (let item of array) { ... }

break → berhenti dari loop
continue → skip ke iterasi berikutnya
⚠️ Pastikan loop punya kondisi berhenti! Kalau tidak, browser bisa hang (infinite loop).

BAB 05 / 06
Fungsi
// Kode yang bisa dipanggil berulang kali
Fungsi = blok kode yang punya nama, bisa dipanggil kapan saja.

3 cara menulis fungsi:

1. function nama(parameter) { ... }
2. const nama = function(param) { ... }
3. const nama = (param) => { ... }

return → mengembalikan nilai dari fungsi.
Tanpa return, fungsi mengembalikan undefined.

BAB 06 / 06
Array &
Objek
// Menyimpan banyak data sekaligus
Array = daftar data berurutan.
let arr = [1, 2, 3] — index mulai dari 0

Method array penting:
• .push(x) → tambah di akhir
• .pop() → hapus dari akhir
• .length → jumlah elemen
• .map(fn) → transformasi tiap elemen
• .filter(fn) → saring elemen

Objek = kumpulan data dengan nama (key-value).
let obj = { nama: "Budi", umur: 17 }
