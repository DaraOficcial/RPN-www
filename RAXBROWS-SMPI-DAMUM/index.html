RAXBROWS
SMPI Darul Mu'minin

Versi 1.0.0 (Android Aplikasi v2026)

RAXBROWS.SMPI-DAMUM adalah aplikasi browser ujian (CBT) resmi yang dirancang khusus untuk lingkungan belajar SMPI Darul Mu'minin. Aplikasi ini dibuat dengan sistem keamanan tinggi untuk memastikan integritas dan kejujuran jalannya ujian, meminimalkan gangguan teknis, serta memberikan kenyamanan visual bagi siswa selama mengerjakan soal.

✓ Terintegrasi penuh dengan Server Ujian SMPI Darul Mu'minin
✓ Fitur Auto-Lock System untuk mencegah kecurangan (ganti tab/aplikasi)
✓ Audio Konfirmasi saat keluar demi meminimalkan human-error
✓ Dilengkapi halaman proteksi kegagalan jaringan (Offline Page)
Unduh Aplikasi (APK)
Kompatibel untuk Android 5.0 (Lollipop) ke atas
